# Metchelyn Baker — Financial Leadership with Purpose

A responsive personal bio site made with plain HTML, CSS, and JavaScript. It has no build step or framework dependencies and is ready for GitHub Pages.

## Preview

Open `index.html` in a browser, or open this folder in VS Code and use a local preview extension.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Add the contents of this folder at the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select your main branch and the root folder, then save.

## Before publishing

- Confirm Mrs. Baker is comfortable with the executive portrait and the use of her biography.
- Confirm that the children’s photos may be shared publicly on the site. The page leaves out children’s names and identifying details; the local image assets will be publicly accessible once deployed.
- Review the biography for accuracy, especially the description of her CFO role and the education and nursing details.
- Add a contact address or professional profile link if she would like visitors to connect.

The site avoids adding specific financial results, credentials, employers, or languages that were not provided.
